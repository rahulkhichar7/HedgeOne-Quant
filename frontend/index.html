Downloads run in the background with one queue per source — Upstox, Delta and CoinDCX download in parallel, each within its own request limit (each also fetches a few securities at once). One failure never stops the rest, and you can close this dialog.
          Limits used: Upstox ≤ 80% of its limits (40/s, 400/min, 1,600 per 30 min), Delta ≤ 75% of its 5-minute quota, CoinDCX ≤ 8/s. When a budget is used up — or the exchange says "too many requests" — that queue waits and resumes by itself (shown in the Status column). Each row can have its own interval and period; the bar above sets them for all ticked rows at once.
          While it runs: ■ Stop on a row stops that security (what it fetched so far is discarded) and the next in its queue starts; ✕ Remove takes a queued one out; ■ Stop all ends everything. Securities that already finished stay saved.
